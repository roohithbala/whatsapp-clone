# 🚀 Start Here: WhatsApp Clone Onboarding

Welcome to the premium WhatsApp Web clone. Follow this guide to get the environment running and explore the main features.

## 1. Environment Setup

1. **Database**: Ensure MongoDB is running on your machine or have an Atlas connection string ready.
2. **Backend**:
   - `cd backend`
   - `npm install`
   - Configure `.env` with `MONGODB_URI` and `JWT_SECRET`.
3. **Frontend**:
   - `cd frontend`
   - `npm install`

## 2. Launching the App

1. Start Backend: `cd backend && npm start`
2. Start Frontend: `cd frontend && npm start`
3. Access: `http://localhost:3000`

## 3. Explore Premium Features

- **Video Calling**: Select a user and click the camera icon in the header to start a real-world WebRTC call.
- **Media Sharing**: Use the "+" button to send photos, videos, and documents. Click sent media to preview.
- **Message Yourself**: Find your own name in the chat list and send private notes.
- **Status Updates**: Go to the Status tab in the sidebar and post your first update.
- **Themes**: Click the ☀️/🌙 icon in the rail to switch between Light and Dark modes.
